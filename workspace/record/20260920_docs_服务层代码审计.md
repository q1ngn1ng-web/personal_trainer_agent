## 结论摘要（详见审计报告）

必须改：

1. **M1** 四失反馈无闭环——客观通道恒 `unknown`（`page_daily.py:193-195` → `signal_service.py:86-92,130-138`），结构性动作无消费者。
2. **M2** 勾选即 `passed`，勾完当前阶段第二天直接跳阶段，且历史阶段项不再复习（`page_daily.py:86-95`、`path_service.py:548-581`）。
3. **M3** 刷新快照/重解析后训练项回指悬空，`validate_item_chunk_links` 无调用方；change 里 B1.5 已标 `[x]`（`source_service.py:134-144,375-404`、`path_service.py:518-545`）。
4. **M4** 知识探测静默只取前 8 个（`edge_service.py:26,90-127`）；真实库 338 个去重标题路径，漏 330 个。
5. **M5** 三态依赖模型自报难度（schema 无 `basis`）；评分调用失败时全部判 `fail`，三态改由题目难度决定（兜底题 → 清一色"未达"、模型题 → 清一色"边缘"），结论由一次故障决定。
