# 20261109 feat 按用途路由模型——轻语义用途可路由轻模型，判分护栏不路由

> 类型：feat｜关联证据：`workspace/evidence/20261109-用途模型路由实验.md`

## 变更摘要

为 LLM 客户端补上按用途路由模型的能力（成本治理，token 方法清单第 2 条）：

1. `src/llm/client.py`：新增 `LIGHT_PURPOSES`（topic_validation / keyword_generation）
   与 `model_for(prompt_name)`——配置了 `LLM_LIGHT_MODEL` 环境变量时，轻语义用途路由到
   轻模型，其余恒为主力；未配置时行为与路由前完全一致（零风险默认）。
2. `_call_api` 增加 `model` 参数；`_run_once` 按用途传模型，且**审计记录真实调用模型**
   （result["model"] 与 llm_calls.model 均为实际模型，不再恒为主力名）。
3. 护栏（写进测试）：**quiz_grade / quiz_variant 永不在 LIGHT_PURPOSES**——换判分模型
   = 换判定分布（grading_cache 键含模型名、换模型自动失效重判），人工一致率标注
   完成前不得路由。
4. `.env.example` 补 `LLM_LIGHT_MODEL` 说明。

## 实测（阿里云免费端点，主力 deepseek-v4.1-flash vs 轻模型 qwen-flash）

两轻用途首发合规均 4/4 不降级；轻模型延迟降至 1/2.6（topic_validation，中位 3067→1178ms）
与 1/4（keyword_generation，4836→1232ms），输入 token 略省；输出质量人工目检同档
（关键词列表覆盖面更广；validation suggestions 略泛化——该用途保持主力也成立，
开关交部署侧按预算定）。详见证据文档。
