# 20261029 feat 判分 prompt 注入学习者记忆上下文

> 类型：feat｜关联 OpenSpec change：`learner-memory-and-grading`（任务 4.3 判分侧）

## 变更摘要

把记忆模块（`memory_service`）的紧凑上下文接进主观题判分 prompt，完成该 change
任务 4.3 的判分侧收口。此前 `render_context` / 题型配比只有测试调用，判分 prompt
（quiz_grade）只注入题目 + 参考答案 + 要点 + 作答，模型判分时看不到"这个用户哪儿不行"。

具体改动：

1. `src/llm/prompts.py`：`QUIZ_GRADE_PROMPT` 追加 `{memory_block}` 占位与口径第 5 条
   （学习者背景仅用于理解作答语境，不得改变判定口径），版本 v1.1.0 → **v1.2.0**。
2. `src/services/memory_service.py`：新增 `grade_memory_block(training_id, item_key)`——
   开关关闭 / 缺 training_id / 无作答数据 / 渲染异常时返回空串（判分不中断）；
   新增 `memory_context_enabled` 开关（`is_/set_memory_context_enabled`，默认开启，
   app_settings 显式写 0 才关闭）。
3. `src/services/answer_service.py`：`_grade_answer` 注入记忆块（带当前 item_key，
   含【当前题背景】段）。
4. `src/services/quiz_service.py`：`grade_with_llm` 注入训练级记忆块（整场多题，
   不锚定单个 item_key）。

## 影响范围

- 仅判分链路（日常训练 `_grade_answer` + 测验 `grade_with_llm`）的 prompt 内容；
  判分口径、规则算分、达标判定、降级路径均不变。
- 开关关闭即回到 v1.1.0 行为（占位为空串），可随时回退。

## 验证

- 全量测试：**268 passed + 30 subtests**（新增 14 条：`test_memory_service.py` 4 条
  记忆块单测；`test_train_points_wiring.py` 新增 `TestGradePromptMemoryContext` 3 条
  集成——有历史作答注入 / 无历史不注入 / 开关关闭不注入）。
- 生产路径端到端实测（阿里云免费端点 `deepseek-v4.1-flash`，DB 副本，真实库零写入）：
  prompt 注入记忆块成功，单次判分 tokens_in=1030（含 Schema 重试反馈），
  判分输出缺失要点理由（score 0.7143 / fail / 缺必答要点），证据见
  `workspace/evidence/20261029-时间成本基准.md` 的「接线后生产路径复测」节。
