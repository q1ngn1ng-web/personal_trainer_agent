# 20260920 · chore · ADR-0019 个人版优先，企业版后置

## 变更摘要

确定实现顺序：先做个人版（意图驱动的自适应训练 AI 教练），企业版保持设计后置。同时纠正了一个关键做法——**不开 git 分支**。

### 触发

用户提出：更想先做个人版本，再开一个分支做企业版，"那这样的话权限管理那里就没有了"。

### 记录的核心内容

1. **不做 git 分支**：企业版是个人版的**超集**，分支是代码隔离而非产品隔离，分叉后必然重复维护并废弃一支。改为同一条代码线，用可选的组织维度区分
2. **个人版 = 只有一个用户的组织**：`org_id` 填默认值、`scope=personal`、角色只有 owner
3. **企业版 change 后置**：`org-and-roles` 与 `training-assignment` 保持提案状态，不 apply、不 archive
4. **"权限管理没有了"要精确**：拆成两半——组织维度字段**保留**（填默认值，成本近乎为零），鉴权与角色**不做**
5. **个人版必须保留企业指标所需的原始数据**：开始日期、首次达标日期、必修完成情况。否则将来企业版算不出"首次达标周期"与"必修覆盖率"
6. **面试材料分两层表述**：个人版说"已实现"，企业版说"已设计、已预留"，不得混说

## 影响范围
