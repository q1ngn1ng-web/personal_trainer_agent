# 20260919 · docs · 面试素材联网调研与证据核实

## 变更摘要

对 `workspace/面试/01-资料来源与知识导入.md` 做了一轮联网核实，把可以从官方文档引用的结论
升级为带 URL 的 `【公开信息】`，并如实记录**没能访问到的部分**。

### 核实的结论

| 结论 | 来源 URL | 抓取结果 |
|---|---|---|
| Anki 的每日数量限额由用户自己设定（New cards/day、Maximum reviews/day），系统只负责按间隔调度 | `https://docs.ankiweb.net/deck-options.html` | 60,253 字节，含 "New Cards/Day"、"Maximum Reviews/Day" 章节 |
| SM-2 算法：`I(n) = I(n-1) × EF`，EF 下限 1.3 | `https://www.super-memory.com/english/ol/sm2.htm` | 9,868 字节，含公式原本与 "E-Factors should not fall below the value of 1.3" |

### 未能核实的部分（保持推测）

| 结论 | 原因 |
|---|---|
| NotebookLM 的引用回指与测验生成形态 | `support.google.com` 连接超时 |
| Quizlet Learn 模式的掌握度调整机制 | Cloudflare 人机校验拦截 |
| Dify 切片参数与混合检索配置项 | 文档站为单页应用，只能抓到营销文案 |
| RAGFlow 深度文档解析能力细节 | `docs.ragflow.io` DNS 解析失败 |

### 规则收紧

`workspace/面试/README.md` 的证据档位规则加了一条：**`【公开信息】` 必须附来源 URL，
无 URL 的一律降级为 `【推测】`**；并新增「调研环境限制」一节，把不可达站点与原因记录在案，
避免下次重复劳动。
