# README Roadmap 去掉"对象扩展（人/LLM/动物）"

> 日期：2026-09-14
> 类型：docs

## 变更摘要

README 的 Roadmap 表里，Phase 2 原写作「多用户、权限、对象扩展（人/LLM/动物）」。这个说法有两个问题：

1. **表述奇怪**：把"动物"和"人"并列成训练对象，读者第一反应是莫名其妙，跟项目定位（学习/技能训练）也对不上。
2. **与真实判断矛盾**：`docs/简历项目包装与深挖问答.md` 里明确写了"不会做人/LLM/动物这种没有用户价值的对象扩展，而是按训练领域配置不同的验证方式"。公开 README 却把它列为计划项，两处说法互相打脸。

改为「多用户、权限、训练领域适配（按领域配置验证方式）」，与项目实际方向一致。

## 影响范围
