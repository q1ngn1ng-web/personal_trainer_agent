# 20260913 · chore · .gitignore 忽略 slim 工具状态

## 变更摘要

`.slim/codemap.json` 是外部文档工具生成的**文件哈希快照**（用于判断哪些源文件变更后需要
重新生成 codemap）。它此前未被 `.gitignore` 覆盖，`git status` 长期显示为未跟踪目录，
存在被 `git add .` 误提交的风险。

该状态文件可随时由工具重建，且其内容会随代码变化立即过期——本次修复正是因为
它最后一次运行（2026-07-25 23:06）早于同日删除 `src/` 根目录 6 个文件的 commit（23:21），
导致快照里仍留着那 6 个已删文件的哈希。

## 变更内容

`.gitignore` 末尾新增一段，与既有"临时文件"段并列：

```
# 工具本地状态（可重建，不入库）
.slim/
```

`.codegraph/` 无需处理——它自带 `.codegraph/.gitignore`（内容为 `*` + `!.gitignore`），
已把数据库、daemon 日志等全部排除。

## 影响范围

- `git status` 不再显示 `?? .slim/`；该目录不会被提交。
- 无代码逻辑改动。
