# understanding-edge-assessment · 理解边缘定位

## Why

理想的教学路径应当**最小化"教已经掌握的"与"教还理解不了的"**——教学恰好发生在学习者理解能力的边缘。因此系统必须先确定**边缘在哪**。

现有 `baseline-diagnosis` 是 3 道诊断题 → 高 / 中 / 低一个档位，有两个问题：

1. **单维标量无法指导取舍**：它答不出"哪些知识点会了（可以跳过）、哪些正好在边缘（该教）、哪些完全不懂（需要前置铺垫）"
2. **把起点和目标压在一条难度轴上**：`level` 说的是想达到什么程度，基线说的是现在在哪，两者不该共用一个刻度

## What Changes

- **探测目标改为逐知识点三态**：已掌握（跳过）/ 边缘（教学重点）/ 未达（先做前置铺垫）
- **探测方式改为分层自适应**：按难度 1→4 递进，答对升档、答错降档，用尽量少的题找到"刚够不着"的位置
- **位置固定为「选好资料来源之后、生成训练路径之前」**，成为路径生成的第三个输入
- **未达知识点必须生成前置铺垫**，且铺垫排在对应知识点之前
- **支持重测**：阶段切换或用户主动请求时重新定位，边缘会随训练移动
- **成本控制**：题量上限、探测进度可见、**允许跳过**（跳过后按中位难度起步，训练中快速修正）
- 修改 `baseline-diagnosis`：三条 Requirement 改写，一条移除
- 沿用 ADR-0017：探测结果写入结构化数据，**不再写入 md**（md 已降级为导出物）

### 关键取舍

| 选择 | 备选方案 | 放弃理由 |
|---|---|---|
| **逐知识点三态** | 单一水平档位 | 档位答不出"该教什么"；只有三态才能决定跳过、重点与铺垫 |
| **分层自适应探测** | 固定 3 道题 | 固定题量无法同时定位多个知识点的边缘；自适应能用更少的题逼近边界 |
| **作为独立一步，放在生成路径之前** | 并入阶段 1 | 阶段 1 的内容本身要按边缘生成，塞进去等于在不知道边缘时先排内容，顺序颠倒 |
| **允许跳过探测** | 强制探测 | 强制会在用户还没看到计划前先考试，增加流失；跳过后用中位难度起步，训练中快速修正 |
| **未达知识点先铺垫** | 直接当训练项安排 | 还理解不了的内容直接教，是打击信心而不是教学 |
| **结果写入结构化数据** | 写入 `01_基线诊断.md` | md 已成为导出物（ADR-0017），不能作为数据源 |

详见 `workspace/decisions/ADR-0018-基线升级为理解边缘定位.md`。

## 非目标（Non-goals）

- **不做固定题库**：探测题在运行时生成或从来源切片构造，不维护一个预先写好的测评题库
- **不做学习风格 / 认知能力测评**：只测"这个知识点会不会"，不测"你是视觉型还是听觉型"
- **不做跨知识点推理能力测量**：只做逐个知识点的边缘定位
- **不引入 embedding**（沿用 ADR-0007）：知识点与题目的匹配仍走 FTS5 与结构信息
- **不规定知识点清单的维护责任方**：本 change 只用它，不决定它由谁维护（关键词白名单的去留同样与本节解耦）

## Capabilities

### New Capabilities

无。本 change 是对现有 `baseline-diagnosis` 的升级，能力 id 保持不变以保留历史。

### Modified Capabilities

- `baseline-diagnosis`: 三条 Requirement 改写为「分层自适应探测」「逐知识点三态」「未达生成前置铺垫」；
  移除「基线诊断完整结果写入训练文件」；新增「理解边缘必须可重测」

## Impact

- **代码**：`src/services/baseline_service.py`（重写为边缘探测服务）、`src/services/`（新增知识点清单推导、三态判定、前置铺垫生成）、`src/db/`（新增 `knowledge_points` / `edge_assessments` 表 + 迁移）、`src/ui/`（探测页）、`src/llm/`（新增用途 `edge_probe` 与 Schema）
- **数据**：新增两张表；`baseline_history` 由"档位历史"改为"知识点三态历史"；`data/trainer.db` 不提交 git
- **依赖**：无新增第三方依赖
- **API**：无（当前项目没有 API 层）
- **测试**：分层探测的升降档逻辑、三态判定、知识点覆盖完整性、跳过后的默认档位、题量上限的纯函数单测
- **证据**：探测题量分布、已掌握被跳过的比例、未达被前置的比例、探测后路径匹配度——**待实测，当前标【待验证】**
