## 3. 分层自适应探测

- [x] 3.1 新增 LLM 用途 `edge_probe`：按知识点与目标难度生成探测题
  - 验收：输出通过 JSON Schema 校验，含 `dimension`、`difficulty`、`question`、`reference_answer`
- [ ] 3.2 实现升降档逻辑：从难度 2 起，答对升档、答错降档
  - 验收：单测覆盖上行（2→3→4）与下行（2→1）两条路径
- [x] 3.3 单知识点题量上限（最多 3 题）与总题量上限
  - 验收：单测断言超限即停止探测并给出已得结论
- [ ] 3.4 探测过程展示进度（已完成 / 剩余题量）
  - 验收：页面显示剩余题量
- [ ] 3.5 探测题进入"近期已用"集合，后续训练与测验不得复用
  - 验收：单测断言后续取题与探测题无交集

## 4. 三态判定（规则层）

- [x] 4.1 三态判定规则：高档全通过=已掌握；中档通过高档失败=边缘；最低档失败=未达
  - 验收：单测覆盖三种分支与边界情况
- [ ] 4.2 记录判定依据（在哪一档通过、哪一档失败）
  - 验收：查询结果中能看到依据
- [ ] 4.3 用户可手动改档，改动留痕
  - 验收：改档后能看到原状态、新状态与时间
- [x] 4.4 判定 MUST NOT 由 LLM 直接给出
  - 验收：代码检查确认三态来自规则函数，LLM 只提供题目与评分

## 5. 前置铺垫

- [ ] 5.1 为未达知识点生成基础概念与推荐资料，并回指来源切片

- [ ] 5.2 路径生成时把铺垫排在对应知识点之前
