# training-execution-feedback · 训练执行与反馈

## Why

整条链路只剩这一段没有设计。现有实现有两个关键缺口：

1. **反馈是单向的**：用户只能勾选完成、自评回忆题对错、写三省，系统却无法理解"这些题太简单了""太宽泛了"这类**主观感受**，也就无法据此调整难度与题量
2. **没有不依赖自评的检验**：学习中最常见的失败是**误以为自己懂了**——尤其在用 AI 学习时，流畅的讲解会强化这种错觉。只靠自评和自述，系统拿不到真实水平，校准就无从谈起

因此这一章要建立两条反馈通道：**主观信号**（用户感受）与**客观测验**（不看自评），并且规定两者冲突时以谁为准。

## What Changes

- 新增**学习信号采集**：快捷标签（太简单 / 太难 / 太宽泛 / 太窄）+ 可选自由文本，映射到《学记》四失
- 新增**信号 → 动作的映射规则**：四失分别对应收敛、拓展、深挖、鼓励四类动作
- 新增**冲突裁决与防抖动**：主观信号与客观表现冲突时**以客观为主**并提示用户；同一天内的结构性调整有次数上限
- 新增**定期测验**：阶段末、时间兜底（默认 7 天）、用户手动触发三种入口
- 新增**测验的独立性约束**：测验题**不得取自刚练过的原题**，须为变式或新题；无提示、不改判分口径
- 新增**达标判定**：训练项达标、阶段达标、任务达标三级判据
- 修改 `daily-execution`：任务卡从"勾选 + 三省"升级为"执行 + 信号采集"；微调逻辑由"只看回忆题正确率"改为"客观表现与主观信号双通道"
- 修改 `weekly-review`：周复盘指标加入信号分布、测验通过率与调整次数
- 沿用 ADR-0001：**LLM 只把自由文本分类成信号，动作由规则层决定**

### 关键取舍

| 选择 | 备选方案 | 放弃理由 |
|---|---|---|
| **主观信号与客观表现双通道** | 只信用户自评 | 用户在 AI 面前容易高估自己；只信自评会让系统被"感觉良好"带偏（ADR-0015） |
| **冲突时以客观为主** | 以用户为主 / 取平均 | 以用户为主会让难度失控；取平均会产生没人说得清的口径。客观表现有数据支撑，优先它，但同时把冲突显式告诉用户 |
| **测验题必须是变式或新题** | 从刚练过的题里抽 | 抽取原题测的是短时记忆，测不出是否真的理解——**恰好是"自我催眠"最严重的地方**（ADR-0016） |
| **测验内容不可由用户挑选** | 让用户自己选题 | 用户会自然地挑有把握的题，测验随即失去校准意义；但**触发时机可以由用户决定** |
| **未通过测验回退重练，而不是重考** | 直接安排补考 | 补考只解决"这次没过"，不解决"这个知识点没掌握"；回退重练才是对症的 |
| **快捷标签 + 可选文本** | 要求用户填写评分表 | 训练过程中填表会直接杀死使用意愿；标签一键完成，愿意多说再写字 |
| 结构性调整设每日上限 | 每次反馈立即调整 | 会让难度来回抖动，用户无所适从；与 ADR-0011 的"连续 3 项超时才降负荷"同一思路 |

详见 `workspace/decisions/ADR-0015-主观信号与客观表现双通道冲突时以客观为主.md` 与
`workspace/decisions/ADR-0016-测验题不得取自刚练过的原题.md`。

## 非目标（Non-goals）

- **不做多模态情绪识别**（面部表情、语音、摄像头）——成本、隐私与实验条件都不具备，用自评与文本信号足够
- 不做实时情绪监测与打断式干预
- 不做用户之间的比较与排行榜（与 `org-and-roles` 一致）
- 不做测验的防作弊机制（单人自用与企业培训场景下，作弊只伤害用户自己）
- 不做 LLM 主观判分的自动放宽：判分口径由 `acceptance` 结构决定，不随情绪信号改变
- 不做题库自动扩充的语义去重（沿用 ADR-0013：先去重只做内容指纹）

## Capabilities

### New Capabilities

- `learning-signal`: 学习信号——快捷标签与自由文本分类、四失映射、信号到动作的规则、冲突裁决与防抖动
- `periodic-assessment`: 定期测验——触发条件、独立性约束、判分与达标、未通过的回退重练

### Modified Capabilities

- `daily-execution`: 任务卡增加信号采集；微调逻辑改为双通道
- `weekly-review`: 复盘指标加入信号分布、测验通过率与调整次数

## Impact

- **代码**：`src/services/`（信号采集与分类、动作裁定、测验编排、达标判定）、`src/db/`（新增 `learning_signals` / `assessments` / `assessment_items` / `adjustment_log` 表）、`src/ui/`（任务卡反馈入口、测验页、复盘页）、`src/llm/`（新增用途 `signal_classify`、`assessment_grade` 与 Schema）
- **数据**：新增四张表；`daily_logs` 扩展字段；`data/trainer.db` 不提交 git
- **依赖**：无新增第三方依赖
- **测试**：信号分类结果校验、冲突裁决规则、每日调整上限、测验取题独立性、三级达标判定的纯函数单测
- **证据**：信号分布、测验通过率、调整前后准确率变化——**待实测，当前标【待验证】**
