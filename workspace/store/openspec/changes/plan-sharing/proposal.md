# plan-sharing · 训练计划分享（链接拉取 + 指定成员推送副本）

> **状态：提案（待实施）**。本文档只做规格，不含实现。
> 依据：2026-11-15 用户需求对齐（个人版组队学习：互相分享资料、分享训练计划帮助别人快速提高）。
> 关联：ADR-0013（内容层与进度层分离）、ADR-0019（个人版优先）、`org-and-roles`（组织与成员）。

## Why

当前训练计划只能自建：一个人建好一套有效的训练（目标澄清 → 资料 → 路径 → 题库 → 判分闭环），
别人想用同样的计划，只能从头再来一遍。组队学习场景的核心诉求是**把跑通的训练流转给另一个人**：

* 管理员/资深成员把踩过坑的计划分享给新手，帮助别人快速提高；
* 成员之间互相分享资料与计划，组成学习小组。

对标调研（2026-11-15）：TrainingPeaks（教练计划库 → 复制到运动员日历，已验证的模式）、
Khan Academy / Duolingo for Schools（分配 + 进度回收）、Anki 共享牌组 / AnkiCollab（协作与权限）。
**差异点**：本系统分享的不是静态内容（牌组/题集），而是**可执行的训练闭环**——副本自带
判分、记忆调度与达标判定。

## What Changes

* **两种分享形态**（用户拍板）：
  1. **组织内链接拉取**：成员为自己的训练计划生成分享链接；组织内成员打开链接预览后**拉取**
     为独立副本（拉取语义，TrainingPeaks 同构）。
  2. **指定成员推送副本**：个人创建的计划可直接分享给特定成员——**分享即复制**，
     把计划**连题库一起**复制一份交付给对方，接收者无需拉取。
* **训练克隆服务**：一次复制 goal / keywords / 资料（连同切片）/ 题库（连同要点清单）/
  路径骨架，并按接收者视角重新锚定生成五轮计划。
* **分享链接**：`share_links` 表 + token；链接仅组织内成员可用（拉取时校验成员身份）。
* **预览**：链接打开显示计划结构（主题 / 目标 / 阶段 / 轮次安排 / 验收标准），
  **不含**题库内容、参考答案与作答数据。
* **溯源**：副本记录来源训练与分享人；原计划的所有者后续修改**不跟随**副本（独立副本语义）。

### 关键决策（详见 design.md）

| 选择 | 备选方案 | 放弃理由 |
| --- | --- | --- |
| 拉取/接收 = **独立副本**（进度从零） | 订阅跟随原计划更新 | 用户拍板（2026-11-15）：训练是个人行为，进度必须私有且互不污染 |
| 题库**随副本复制**（练习计数与冷却期重置） | 副本共享引用原题库 | 共享引用会让双方互相影响冷却期与达标状态，违背进度分离 |
| 链接仅组织内成员可用 | 任何持有链接者 | 个人版组队场景以组织为边界；跨组织分享后置 |
| 预览不含题库与参考答案 | 全量预览 | 防止"白嫖题库"与背题，保持判分证据链的可信度 |

## 非目标（后置，不进本期）

* **作业提交验收模式**：第三方外部认证 / LLM 判不了的条目由成员提交凭证、人工验收——
  用户决策暂缓（2026-11-15），待判分证据链闭环后再立项。
* 订阅式共享（原计划更新跟随）。
* 跨组织分享与公开链接。
* 通知系统（分享后提醒接收者）。

## Impact

* 新表 `share_links`；`trainings` 新增溯源列 `shared_from_training_id` / `shared_by_user_id`。
* 新增训练克隆服务与 4 个端点（生成链接 / 预览 / 拉取 / 推送指定成员）。
* 前端：分享入口（我的训练/训练详情）、链接预览页、拉取按钮、推送成员选择器。
* 判分/记忆/导入链路不变。
