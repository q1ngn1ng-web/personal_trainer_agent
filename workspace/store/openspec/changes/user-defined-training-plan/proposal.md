# user-defined-training-plan · 用户自定义训练计划（总时长×次数，动态配比会话，终测定通过）

> 状态：**仅提案，设计决策已全部拍板（2026-11-22），未实施**。自包含交接文档。
> 来源：2026-11-22 用户产品决策。**实质修订 ADR-0021（固定五轮锚定创建日）**——实施时写新 ADR。

## Why

现模型（ADR-0021）：五轮固定间隔、**每轮覆盖全部训练项**、完成=必修覆盖+最近测验通过。三个偏差：

1. **投入参数无家可归**：总时长、训练次数既不问也不个性化（澄清提示词第 6/7 条禁问，
   路径用内置默认 2 周×5 天×30 分钟）；
2. **每轮全覆盖=负载尖峰**：12 题在第 1/3/7/15/30 天全量脉冲；
3. **完成判定分散**：连续 2 次通过/14 天小测/必修覆盖三个口径叠加，用户心智是
   "最后考一下，过了就算完成"。

## What Changes

**A. 澄清阶段收集投入参数（UI 控件，非对话）**

澄清步展示"训练节奏"卡片：**总时长**（周，默认 2，范围 1-8）× **训练次数**（默认 3，范围 2-6），
写入 goal 快照 `horizon_days` / `session_count`（field_sources=user_input）。
提示词第 6/7 条修订：**禁的是 LLM 对话追问，收集职责移交 UI 控件**；
卡片按知识点数量与等级显示推荐值。

**B. 会话配比模型（用户拍板，替代原"每项最少 2 次"）**

- **总量覆盖硬约束**：每个训练项至少出现 **1 次**（跨会话并集 = 100% 覆盖，不可协商）；
- **单次配比随次数递减、重叠递增**（用户原案）：
  - 1 次训练：单次覆盖 100%；
  - 2 次训练：每次覆盖 70%，**重叠 40%** = 20% 已知巩固（上次答对的）+ 20% 错题回炉（上次答错的）；
  - 3 次及以上依此类推（单次占比递减、重叠池递增；精确配比表实施时校准，标【待定】）；
- **正确率恒稳控制器（动态配比）**：以最近一次会话判分正确率为输入，目标带 **80%±10%**：
  - >90%（太容易）：降低"已知巩固"占比、提高错题回炉/新知占比（镜像外推，【待定】校准）；
  - 70-90%（目标带）：维持当前配比（20% 已知 + 20% 错题）；
  - 60-70%（偏难）：复习池改 **25% 已答对 + 15% 错题**；
  - <60%（太难）：**30% 已答对 + 10% 错题**（多巩固已知、少回炉，把正确率拉回带内）；
  - "以此类推" = 阶梯表线性外推，实施时校准；
- **五星"值得复习率"排序**（不是难度，是"该不该再练"）：错题 > 正确题；
  先对后错（回归）介于二者之间；其他情形（连续答对递减、长期未练衰减等）实施校准【待定】。
  控制器定各桶占比，星序定桶内谁先进入清单；
- **终测不过 → 追加一轮**：按同一动态配比机制重新组一个会话周期（已稳定项自动进入
  "已知巩固"池），终测再次把关；周期小测**保留**（每 14 天，与终测并存）；
- **会话日期由系统安排**（horizon 内近似均匀摊开），**允许用户提前练**（提前完成只解锁，
  不改后续会话的排期语义）。

**C. 与既有工作的收编关系**

| 对象 | 关系 |
| --- | --- |
| performance-driven-scheduling | 阶梯被**配比控制器+五星排序**吸收（表现→配比，而非间隔挪动）；实施顺序：本 change 定骨架 |
| adaptive-practice-composition | "错题回炉"由配比模型原生覆盖（20% 错题池）；"提前练"由允许提前原生覆盖——该 backlog 建议撤销合并 |
| coach-memory-three-layers | 连败信号喂配比控制器；daily_minutes_target 喂单次容量；不受影响 |
| 判分/达标/graded attempt | **零变化**（本 change 只动排期与完成门） |

### 关键取舍

| 选择 | 备选 | 放弃理由 |
| --- | --- | --- |
| 并集 100% + 重叠巩固 | 每项最少 2 次硬约束 | 用户拍板：覆盖下限降到 1 次，巩固交给重叠池——次数少时更尊重用户约束 |
| 正确率恒稳控制器 | 固定配比 | 静态配比无法适应"太容易/太难"的体感；控制器让难度自动回到 80%±10% 目标带 |
| 五星复习价值排序 | 纯随机抽复习 | 错题优先、稳定答对靠后是学习常识；排序让有限的复习池花在刀刃上 |
| 终测单独把关 | 沿用"最近测验通过" | 用户心智"最后考一下"；终测覆盖全部必修，与 14 天小测分工 |
| 允许提前练 | 禁止提前 | 用户拍板允许；提前完成只解锁后续，不改排期口径 |

## 非目标（Non-goals）

- 不改判分公式/verdict/达标 streak 语义（graded attempt 零变化）
- 不做 LLM 参与分配或配比决策（全部纯函数；LLM 只出推荐叙述）
- 不迁移存量训练（schedule_mode='legacy_v21' 隔离）
- 不做逐日精确日历；不做跨训练联合排期
