# daily-execution Specification

## MODIFIED Requirements

### Requirement: 系统呈现今日任务卡

系统 SHALL 从**训练计划**（`plan_items`）读取 `plan_date` 等于当天的计划项，以今日任务卡呈现。
系统 MUST NOT 再从复习日历文件（`04_复习日历` / `05_主动回忆题`）抽取任务——十份 md 已按 ADR-0017 降级为导出物，不再是数据源。

今日任务卡 SHALL 提供两种粒度：**跨训练聚合视图**（主入口，位于首页）与**单训练视图**（从某个训练内进入）。
计划尚未生成时，系统 MUST 显式提示「尚未生成训练计划」并提供生成入口，
MUST NOT 用"当前阶段的前若干项"临时顶替今日任务。

#### Scenario: 跨训练聚合视图

- **WHEN** 用户在首页打开今日训练
- **THEN** 系统按当天日期聚合所有训练的待练计划项，按训练（主题）分组展示
- **THEN** 每项展示所属主题、知识点、题型与预计时长

#### Scenario: 单训练视图

- **WHEN** 用户从某个训练进入今日任务
- **THEN** 只展示该训练当天的计划项，展示规则与聚合视图一致

#### Scenario: 间隔复习生效

- **WHEN** 某训练项被标记为「练过」
- **THEN** 系统按 1 / 3 / 7 / 15 / 30 天间隔把复习项写入训练计划
- **THEN** 复习项到期的当天出现在任务卡里，无需用户主动查找

#### Scenario: 待补项不消失

- **WHEN** 存在早于今天且未勾选的计划项
- **THEN** 任务卡显示待补区，列出这些项及其原定日期

#### Scenario: 尚未生成计划

- **WHEN** 路径已确认但训练计划尚未生成
- **THEN** 任务卡显示「尚未生成训练计划」与生成入口
- **THEN** MUST NOT 展示"当前阶段的前 N 项"作为今日任务
