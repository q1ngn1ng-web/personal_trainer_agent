# progress-dashboard Specification

## MODIFIED Requirements

### Requirement: 首页展示训练列表与项目说明
系统 SHALL 在首页（Streamlit 首页）展示：
- **「今日训练」区块（位于首屏顶部）**：当天到期的计划项，按训练（主题）分组，展示每组条数、预计时长与跨训练合计，并提供进入今日任务卡的入口
- 项目说明（产品定位 + 使用方法 + 真主题 demo 入口）
- 所有训练列表（topic、状态、当前基线、已坚持天数、最近活跃时间）
- 「新建训练」按钮

「今日训练」区块 SHALL 只读取计划数据，MUST NOT 修改任何训练状态（沿用「仪表盘只读」约束）。
当天没有计划项时，区块 MUST 展示休息日空态（含下次练习日与预计项数），MUST NOT 只显示空白或"无任务"。

#### Scenario: 首页加载
- **WHEN** 用户打开应用根路径
- **THEN** 首页可见，按上述结构渲染
- **THEN** 训练列表按 `last_active_at` 倒序排列

#### Scenario: 今日训练聚合
- **WHEN** 两个训练当天都有计划项
- **THEN** 「今日训练」区块同时展示两组及其条数与合计时长
- **THEN** 点击入口可进入今日任务卡

#### Scenario: 休息日空态
- **WHEN** 当天没有任何计划项
- **THEN** 区块显示"今天是休息日"以及下次练习日与预计项数

#### Scenario: 今日训练区块不可写
- **WHEN** 用户在「今日训练」区块内点击、悬停
- **THEN** 训练与计划数据 MUST NOT 被修改
- **THEN** 勾选等写操作只发生在今日任务卡内
