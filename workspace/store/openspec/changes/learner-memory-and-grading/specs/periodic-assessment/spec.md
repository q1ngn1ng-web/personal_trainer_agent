# periodic-assessment Specification

## ADDED Requirements

### Requirement: 测验结束后给出整场评分与综合反馈

系统 SHALL 在测验完成后，基于本轮各题的判分结果聚合出整场评分并写入测验记录，
同时产出综合反馈，至少包含：总分、各知识点掌握情况、薄弱点、下一步建议。
整场评分 MUST 由确定性聚合得出，MUST NOT 把整场原始作答重新交给模型判一遍。

#### Scenario: 测验完成即出分

- **WHEN** 用户完成一场测验的全部题目
- **THEN** 系统写入该场测验的总分与是否通过

#### Scenario: 综合反馈指出具体薄弱点

- **WHEN** 系统生成整场反馈
- **THEN** 反馈指出具体的薄弱知识点与对应错误类型，而非泛泛而谈

### Requirement: 下一场测验的题型配比按薄弱项调整

系统 SHALL 依据上一场测验暴露的题型失误分布调整下一场的题型配比，
调整 SHALL 在下一场测验生效，MUST NOT 在本场中途改变已完成题目。

#### Scenario: 选择题失误多则提高选择题占比

- **WHEN** 上一场测验中选择题失误比例显著高于其他题型
- **THEN** 下一场测验的选择题占比上升

#### Scenario: 调整在下一场生效

- **WHEN** 系统根据薄弱项调整题型配比
- **THEN** 本场已生成的题目不受影响
