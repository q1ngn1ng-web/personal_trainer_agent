# 面试素材

本目录存放面试用材料：竞品调研、差异化说明、技术选型依据、追问预案。

## 产品定位：分两层说，不要混

依据 `workspace/decisions/ADR-0019-个人版优先企业版后置同一条代码线.md`。

| 层 | 状态 | 面试怎么说 |
|---|---|---|
| **个人版**：意图驱动的自适应训练 AI 教练 | 已实现（每日自用） | "我自己每天在用，这是真实数据" |
| **企业版**：组织化培训与达标管理 | **已设计、已预留**，未实现 | "我知道它怎么长成企业级，数据隔离已经留好了" |

**两条纪律**：

1. **不得把企业版说成已实现**——讲了多租户却拿不出企业数据，反而扣分
2. **企业版设计不是白做的**：它证明架构前瞻性（内容层/进度层分离、`org_id` 预留、指标口径先定），讲成"规划"是加分项

## 写作规则（与 `workspace/evidence/` 配套）

1. **本文档里的每个数字都必须在 `workspace/evidence/` 有出处**；没有实测的一律写 `【待实测】`。
2. **竞品结论必须区分三种来源**：
   - `【公开信息】`：产品官网、文档、论文里明确写的——**必须附来源 URL**，无 URL 的一律降级为 `【推测】`
   - `【推测】`：根据公开行为反推的实现方式，未经验证
   - `【已实测】`：自己动手试过并留了截图
3. 只有 `【已实测】` 的结论可以写进简历或在面试里作为强主张；`【推测】` 可以说，但要主动标注"这是我从外部行为推断的"。
