# 面试素材

本目录存放面试用材料：竞品调研、差异化说明、技术选型依据、追问预案。

## 写作规则（与 `workspace/evidence/` 配套）

1. **本文档里的每个数字都必须在 `workspace/evidence/` 有出处**；没有实测的一律写 `【待实测】`。
2. **竞品结论必须区分三种来源**：
   - `【公开信息】`：产品官网、文档、论文里明确写的
   - `【推测】`：根据公开行为反推的实现方式，未经验证
   - `【已实测】`：自己动手试过并留了截图
3. 只有 `【已实测】` 的结论可以写进简历或在面试里作为强主张；`【推测】` 可以说，但要主动标注"这是我从外部行为推断的"。
