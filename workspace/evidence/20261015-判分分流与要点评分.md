# 20261015 判分分流与要点评分（证据）

> 关联 OpenSpec change：`learner-memory-and-grading`（tasks 1.1—1.4、2.1—2.4）
> 关联 ADR：ADR-0022

## 一、口径

| 项 | 口径 |
|---|---|
| 覆盖率 | Σ(命中权重 + 0.5 × 部分命中权重) ÷ Σ总权重 |
| 正确性 | 1 − 错误要点权重 ÷ 作答涉及的要点权重（未作答不参与） |
| 得分 | 覆盖率 × 正确性（0—1） |
| 必答否决 | 必答要点未命中 → 该题不通过 |
| 分流规则 | choice / fill 确定性判分；qa 要点评分 |

## 三、关键断言

1. **客观题不调用大模型**：`test_objective_grading_does_not_call_llm` 用 monkeypatch 把
   `src.llm.client.complete` 替换为抛异常的桩，选择题与填空题判分仍正常通过——证明这两条路径没有触碰模型。
   判分结果中的 `graded_by` 字段固定为 `rule`，可作为后续接入时的断言点。
2. **答满但说反 < 只答对两条**：`test_wrong_answer_worse_than_missing` 断言前者的 `score` 严格更小。
3. **三点答两点 = 2/3**：`test_coverage_two_of_three`（等权情形下 `coverage == 2/3`）。
4. **必答缺失一票否决**：`test_required_missing_vetoes_pass`，且 `required_missing` 可定位到具体要点。
5. **迁移可重复执行**：`test_migrate_adds_grading_columns_to_old_db` 在模拟老库上补列并建表，
   第二次调用返回空列表。
