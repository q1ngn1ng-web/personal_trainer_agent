## 五、几个值得记住的判断

1. **向导顺序修正**：基础教育学上"教学应在理解边缘"，而边缘要靠答题确定——所以**先有资料、再探测、最后生成路径**。你在 BACKLOG 里指出的顺序问题是根上的问题。
2. **十份 md 已经退出主流程**：现在创建训练不再强制生成十个文件（ADR-0017 说它该降级为导出物，代码这次跟上了——直接从流程里去掉）。
3. **"主题不够具体"不再拦人**：那条老校验随老步骤一起移除；"范围太宽"这类判断归到理解边缘定位阶段。
4. **预算由规则算**：模型只能建议周期/频次/时长，总量超预算直接拒绝并让它压缩重试。
5. **`llm_calls` 去掉了 call_purpose 的 CHECK**：以后新增 LLM 用途不再需要重建表。

## 六、踩过的坑（都已修复并留档）

| 坑 | 教训 |
|---|---|
| 迁移把生产库改坏（数据留在 `trainings_old`） | 重建表必须 **`foreign_keys=OFF` + `legacy_alter_table=ON` + 显式事务**；Python sqlite3 的 DDL 隐式提交会留下半成品 |
| 真实模型把正确率返回成 80 而不是 0.8 | 单测样本自己写，只会覆盖自己想到的口径；**必须跑真实调用** |
| 资料页"操作成功"提示看不见 | `st.rerun()` 会冲掉提示，要用 session_state 暂存 |
| `compute_impact` 自递归 | 服务层与领域层同名函数，导入时要用别名 |
| PDF 测试抽取全是省略号 | PyMuPDF 默认字体渲染不了中文，得指定内置 CJK 字体 |
