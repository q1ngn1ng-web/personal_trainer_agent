# ADR-0018 基线诊断升级为「理解边缘定位」

- **状态**：已采纳
- **日期**：2026-09-20
- **关联**：修改 `baseline-diagnosis`；成为 `training-path-generation` 的输入；复用 `periodic-assessment` 的取题与判分机制；难度口径沿用 ADR-0010

## 背景

理想的教学路径应当**最小化"教已经掌握的"与"教还理解不了的"**，教学恰好发生在学习者理解能力的边缘。因此系统必须先确定**理解边缘在哪**。

现有实现是 3 道诊断题 → 高 / 中 / 低一个档位。单一档位有两个问题：

1. 它只给一个标量，回答不了"哪些已经会了（可以跳过）、哪些正好在边缘（该教）、哪些完全不懂（需要前置铺垫）"
2. 它把"起点"和"目标"压在同一条难度轴上，而两者本就不该共用一个刻度——`level` 说的是想达到什么程度，基线说的是现在在哪

## 备选方案

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| 3 题诊断 → 高 / 中 / 低单一档位（现状） | 实现简单，一步出结果 | 单维标量无法指导逐知识点的取舍；教已掌握的浪费用户时间，教还不会的打击信心 | 否 |
| 取消前置探测，从中位难度开始，用实际表现反推 | 少一步 | 前若干训练项必然错配，用户要先浪费一批题目才进入有效区间 | 否 |
| **逐知识点三态 + 分层自适应探测** | 直接产出"该教什么"的答案，路径不浪费 | 需要知识点清单与探测逻辑，题量比原来多 | **采纳** |

## 决策

1. **探测目标从"水平档位"改为"逐知识点三态"**：
   - **已掌握**：连续通过高档位 → **跳过**，只保留低频维护复习
   - **边缘**：中档通过、高档失败 → **教学重点**
   - **未达**：低档即失败 → 先做前置铺垫，或下调目标
2. **探测方式为分层自适应**：对每个知识点按难度 1→4 递进探测，答对升档、答错降档，用尽量少的题找到"刚够不着"的位置。
3. **位置固定为「选好资料来源之后、生成训练路径之前」**：探测所需的知识点来自来源切片；路径生成必须以探测结果为起点。
4. **不并入阶段 1**：阶段 1 的内容本身就要按边缘生成；把探测放进阶段 1，等于在不知道边缘的情况下先安排内容，顺序是反的。
5. **复用测验机制**：取题、判分、无提示等约束复用 `periodic-assessment`，不另建一套评测体系。
6. **可重测**：边缘会随训练移动，支持在阶段切换或用户主动请求时重新定位，复用定期测验的入口。
7. **成本控制**：题量设上限；探测过程即时展示进度；**允许跳过**——跳过后按中位难度起步，并在训练中快速修正。

## 与知识点清单的关系

探测需要一个"测量对象清单"。本决策**不规定**该清单的来源：它可以只从来源切片与验收标准推导，因此**关键词白名单的去留不影响本条**。两者解耦，白名单留待后续单独决策。

## 后果与验证

- **代价**：比原来的 3 题多花题量；探测质量依赖知识点清单的质量
- **收益**：教学内容集中在边缘——已掌握的跳过、未达的先铺垫，这是"路径不浪费"的前提
- **验证方式**：
  - 统计"已掌握被跳过"与"未达被前置"的比例，确认探测确实在起作用
  - 对比有无探测时的路径匹配度——**【待实测】**
- **重评估触发条件**：若探测题量导致用户流失率显著上升，考虑降低探测粒度（例如按章节而非按知识点）
