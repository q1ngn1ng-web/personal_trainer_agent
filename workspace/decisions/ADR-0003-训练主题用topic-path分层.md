# ADR-0003 训练主题用 topic_path 分层，暂不建分类表

- **状态**：已采纳
- **日期**：2026-09-19
- **关联**：spec `trainer-generation`、spec `daily-execution`

## 背景

"八股"这类节点是分类，不是可训练任务。主题平铺会让用户无法聚合进度，也无法表达 `八股/Java基础`、`八股/Redis` 的父子关系；但把分类当成可训练任务，又会产生"开始训练八股"这种无法验收的状态。

## 备选方案

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| 主题平铺 | 结构最简单 | 无法聚合进度，无法表达层级 | 否 |
| 独立分类表 + 外键 | 支持重命名、跨分类移动、分类级配置与权限 | 当前没有这些需求，增加建表与迁移成本 | 暂不 |
| **JSON 路径（topic_path / topic_key）** | 零表结构成本即可表达层级 | 无法重命名，无分类级配置 | **采纳** |

## 决策

- 用 `topic_path`（如 `["八股", "Redis"]`）与 `topic_key`（如 `八股/redis`）表达层级
- 叶子节点承载训练计划与复习调度；分类节点只做聚合与展示
- 不建独立分类表

## 后果与验证

- **代价**：分类重命名、跨分类移动、分类级权限与配置目前无法表达
- **验证方式**：新建训练时主题必须落到叶子节点；见 spec `trainer-generation` 与 `daily-execution`
- **重评估触发条件**：出现重命名、跨分类移动或分类级配置需求时，迁移到独立分类表
