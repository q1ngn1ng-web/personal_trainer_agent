# ADR-0002 评测用 strict/fuzzy 组合分，暂不上 embedding

- **状态**：已采纳
- **日期**：2026-09-19
- **关联**：评测模块、spec `daily-execution`

## 背景

背诵与答题评测要解决的核心问题是"意思对了但漏了关键点"不能算通过。单一余弦相似度只看语义接近，不衡量漏句、顺序和完整度，重复堆词同样能拉高相似度。

同时，当前阶段真正卡住产品的不是"跨大量资料的语义检索"，而是"评测结果是否可解释、可校准"。

## 备选方案

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| 单一余弦相似度 + 固定阈值 | 实现最简单 | 不看漏句与顺序，可被堆词刷分，阈值随模型漂移 | 否 |
| 全部交给 LLM 判分 | 语义理解最强，无需维护权重 | 成本高、结果不稳定、同输入可能给不同分 | 否（仅作不确定区间的裁判） |
| **strict / fuzzy 双模式 + 组合分** | 可解释，能定位错误位置，成本可控 | 需维护关键句与权重，阈值需标注样本校准 | **采纳** |

## 决策

- strict 模式：归一化文本 + diff，定位漏字、错词与顺序错误
- fuzzy 模式：句子级 n-gram + 关键句覆盖 + 顺序相似度加权（0.5 / 0.3 / 0.2 为可配置初值）
- 只有落在不确定区间时才调用 LLM 判断语义等价
- 关键句在导入时由 LLM 提议、用户可修改，以结构化 `segment_id + weight + reason` 存储
- embedding 不在当前范围内

## 后果与验证

- **代价**：关键句与权重需要人工确认；组合权重目前是启发式初值，不是调优结果
- **验证方式**：用人工标注样本校准阈值——**尚未建立标注集，标【待验证】**
- **重评估触发条件**：出现跨资料检索、相似题推荐或海量资料匹配需求时，再引入 embedding
