# 决策记录（ADR）

本目录记录"为什么选 A 不选 B"。每个决策一个文件，一页以内。

## 命名与状态

- 文件：`ADR-XXXX-简短描述.md`，四位数字递增，编号不复用
- 状态：`提议中` / `已采纳` / `已被 ADR-XXXX 取代` / `已废弃`
- **已采纳的 ADR 不修改正文**；决策变了就新建一条，并把旧的那条状态改成"已被 ADR-XXXX 取代"

## 什么时候必须写

- 引入或更换技术组件（数据库、向量库、模型、编排框架、部署方式）
- 在两个方案之间做了明确取舍（算法、截断策略、融合方式、评测口径）
- 设定了一条"以后不要违反"的约束
