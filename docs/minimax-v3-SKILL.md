# 个人训练师 Skill

> **核心承诺**：你说一个训练目标，我帮你跑通十要素闭环，生成 10 份文件，你照着每天做就行。每周复盘一次，基线自动升级。

---

## 🎯 何时使用本 Skill

当你说出以下任意一句话时**立即触发**：

- "我要训练 [主题]" / "我要学 [主题]" / "我想提升 [技能]"
- "帮我制定 [主题] 的训练计划"
- "我要练 [技能]，练到 [水平]"
- "用 personal-trainer 帮我训练 [主题]"
- "我要在 [时长] 内学会 [技能]"

**不适用**（直接拒绝或转交）：
- 临时答疑（"X 是什么意思"）→ 不触发
- 短期信息查询（"X 文档在哪"）→ 不触发
- 已经制定好计划、只要执行（"我今天要复习 X"）→ 不触发（这属于"省"环节，应该直接用 `daily-review` 子命令）

## 🚀 工作流（三阶段）

```
阶段一：基线诊断 + 文件生成（首次使用，30-60 分钟）
   ↓
阶段二：每日执行（每天 15-30 分钟）
   ↓
阶段三：周复盘 + 基线更新（每周 30 分钟）
   ↓
循环：阶段二 ↔ 阶段三，直到达成"小成"或"大成"里程碑
```

### 阶段一：基线诊断 + 文件生成（首次）

**Step 1.1 — 接收用户输入**

向用户确认以下 5 个核心参数（如未提供则逐项询问）：

```
请告诉我：
1. 训练主题（具体到能验证的程度）？
2. 你的背景？（零基础 / 有过接触 / 已有基础）
3. 目标水平？（业余 / 专业 / 专家 / 大师）
4. 时间投入？（每天能花多少时间？总共想投入多久？）
5. 应用场景？（工作 / 兴趣 / 考试 / 副业）
```

**反例**（主题太宽，需收窄）：
- ❌ "学编程" → ✅ "用 Python 写自动化脚本"
- ❌ "学英语" → ✅ "通过雅思 7 分"
- ❌ "学钢琴" → ✅ "能流畅弹《致爱丽丝》"
- ❌ "提升写作" → ✅ "写公众号能稳定 1 万+ 阅读"

**Step 1.2 — 基线诊断（前置拷问 3 问）**

根据训练主题，**生成 2-3 道前置诊断题**，测试用户的"暂时性学会"水平。

**诊断题设计原则**：
- 不查资料 30 秒内能答出 = 已掌握
- 需要思考但能答对 = 模糊掌握
- 完全不会 / 答错 = 缺失基线

**示例（训练主题：Python 自动化）**：

```
Q1: Python 中 list 和 tuple 的核心区别是什么？（一句话）
Q2: 写一段代码，用 for 循环打印 1-10 的偶数。（30 秒内）
Q3: 你知道 requests 库吗？它是做什么的？（一句话）
```

**判定**：
- 3/3 答出 → 基线"高"，进入正式训练，跳过预训练清单
- 2/3 答出 → 基线"中"，进入正式训练，补强未答对的点
- ≤ 1/3 答出 → 基线"低"，**先生成"预训练清单"**（5-10 个基础概念 + 推荐资料），用户学完后再诊断一次

**Step 1.3 — 生成 10 份训练文件**

在 `/workspace/training_[主题]/` 目录下生成以下 10 个文件（**全用中文，按用户具体主题定制**）：

```
training_[主题]/
├── 00_对象档案.md           # ①对象 - 你的画像
├── 01_基线诊断.md           # ②基 - 当前水平快照
├── 02_训练目标.md           # ③的 - 分层目标
├── 03_资料库.md             # ④器 - 学习材料
├── 04_复习日历.md           # ⑤序 - 时间安排
├── 05_主动回忆题.md         # ⑥术 - 自测题
├── 06_环境配置.md           # ⑦境 - 物理+社会+信息
├── 07_奖励机制.md           # ⑧奖 - 动力系统
├── 08_每日反省.md           # ⑨省 - 复盘
└── 09_边界与止.md           # ⑩止 - 不做什么
```

**每份文件的内容模板**（详见后文「文件模板」章节）。

**Step 1.4 — 训练概览（00_对象档案.md 的最后一段）**

输出一段"训练一眼览"，让用户 1 分钟内明白接下来要做什么。

---

### 阶段二：每日执行（每天 15-30 分钟）

**用户每天只需做 4 件事**：

```
1. 打开 04_复习日历.md → 看今天要复习/学什么
2. 用 05_主动回忆题.md → 闭卷自测（不查资料）
3. 打开 08_每日反省.md → 填三省 + 元认知
4. 完成任务后去 07_奖励机制.md → 领取今日奖励
```

**自动提醒**（如果 Skill 部署在支持 cron 的环境）：

- 每天 9:00 推送今日训练任务（来自 04_复习日历.md）
- 每天 21:00 推送三省提醒
- 每周日 18:00 推送周复盘提醒

---

### 阶段三：周复盘 + 基线更新（每周 30 分钟）

**每周日晚上 18:00 触发**：

1. 用户打开 `08_每日反省.md` 汇总本周数据
2. 回答 3 个核心问题：
   - 本周响应率（任务完成率）如何？
   - 本周最大卡点是什么？
   - 下周需要调整什么（基线/目标/资料/奖励）？
3. Skill 根据回答，**自动更新**：
   - `01_基线诊断.md` → 升级基线
   - `02_训练目标.md` → 校准进度
   - `05_主动回忆题.md` → 增加新题、淘汰已掌握题
   - `07_奖励机制.md` → 调整奖励频率/价值
4. 输出"本周训练简报"给用户

### 07_奖励机制.md（⑧奖）

```markdown
# 奖励机制 - [训练主题]

> 《论语·学而》：学而时习之，不亦说乎？
> 《学记》：不兴其艺，不能乐学。
> 现代：Self-Determination Theory（自主+胜任+关系）

## 🎁 奖励设计三原则

1. **及时**：行为发生后越快给越好（5 分钟内）
2. **具体**：针对具体行为给（不是"你真棒"，是"你刚才那段代码的命名很好"）
3. **可变性**：固定奖励会习惯化（Hedonic Adaptation），要偶尔"惊喜"

## 💰 外在奖励

### 物质奖励
| 行为 | 奖励 | 触发时机 |
|------|------|---------|
| 完成每日任务 | [小礼物/奶茶/零食] | 当晚 |
| 完成周目标 | [一顿好饭/一件小东西] | 周末 |
| 完成阶段里程碑 | [一次旅行/一个想要的东西] | 阶段末 |

### 社会奖励
- [ ] 朋友圈分享成果（每周一次）
- [ ] 给朋友/家人讲学到的东西
- [ ] 写公众号/博客记录
- [ ] 参加社群分享/挑战赛

### 机会奖励
- [完成 X 阶段后可以解锁 Y 项目]
- [达成 Z 水平后可以申请 W 机会]

## 🧠 内在奖励（最持久）

### 胜任感（Competence）
- 设计难度梯度：任务难度 = 当前能力 + 1
- 每次小成功 → 多巴胺 → 想继续

### 自主感（Autonomy）
- 自己选学习内容
- 自己定学习节奏
- 自己选学习方式
- 每周给自己 1 小时"自由探索"时间（不按计划，纯凭兴趣）

### 关系感（Relatedness）
- 找到 1-2 个学习伙伴
- 加入相关社群
- 找 1 个导师/教练
- 给别人讲（教是最好的学）

### 好奇心满足
- 每周留 1 个"为什么"问题
- 研究透彻后记录在笔记
- 设立"趣味挑战"（如：今天用刚学的 X 写个段子）

### 意义感
- 写下"我学这个是为了 ____"
- 每周看一次
- 想象"一年后我掌握 X 后能 ____"

## 📅 奖励日历

| 触发条件 | 奖励 | 自我承诺 |
|---------|------|---------|
| 完成今日任务 | [具体] | [签名] |
| 完成周任务 80% | [具体] | |
| 完成阶段目标 | [具体] | |
| 连续 7 天全勤 | [具体] | |
| 达成里程碑 | [大奖励] | |

## ⚠️ 反模式（避免）

- ❌ 物质奖励为主 → 失去内在动机
- ❌ 延迟太久 → 当事人已忘
- ❌ 错行为给奖励 → 强化错行为
- ❌ 比较奖励（"别人比你快"） → 削弱自我决定感
- ❌ 只在失败时关注 → 回避训练

## 🔄 奖励升级（每月调一次）

每月 1 日检查：
- 上月哪些奖励有效？
- 哪些奖励已"贬值"？
- 本月要尝试什么新奖励？
- 内在 vs 外在比例是否合适（建议 7:3 内在:外在）？
```

### 09_边界与止.md（⑩止）

```markdown
# 边界与止 - [训练主题]

> 《大学》：知止而后有定。
> 《论语》：过犹不及。

## 🛑 不做什么（明确边界）

> 没有边界的训练是涣散。

### 范围约束
- 训练只针对 [主题]，不跑到其他领域
- 关联发散不超过 1 个"跳转"
  - 例：学 Python 时跳到算法 OK，跳到哲学 = 过界

### 时间约束
- 单次训练 ≤ [90] 分钟
- 每日训练 ≤ [4-6] 小时
- 每周休息 1 天（强制）

### 目标约束
- 阶段目标未达成前不开新坑
- 同时进行的训练主题 ≤ 2 个

### 方法约束
- 同时试的方法 ≤ 1 种（先跑 2 周看效果）
- 工具不频繁切换

## 🚦 止的信号（出现立即停）

- **疲惫**：连续 3 天训练质量下降
- **厌倦**：对训练产生强烈抵触
- **伤害**：身体不适/心理压力过大
- **过拟合**：能完美回忆题但不会应用
- **完美主义**：因为"不够完美"而拖延

## 🔄 收放节奏

| 阶段 | 状态 | 时长 |
|------|------|------|
| 紧 | 高强度（冲刺） | 1-2 周 |
| 收 | 巩固消化 | 1 周 |
| 紧 | 高强度 | 1-2 周 |
| 收 | 巩固消化 | 1 周 |
| 放 | 自由探索 / 休息 | 1 周 |

## 🛡️ 应急方案

**今天状态不好**：
- 选项 A：完成 50% 任务 + 早睡
- 选项 B：纯回忆（不学新内容）
- 选项 C：直接休息（每周允许 1 次）

**连续 3 天没完成**：
- 检查是不是目标定太高 → 降低 30%
- 检查是不是奖励失效 → 换奖励
- 检查是不是环境出问题 → 改环境
- 检查是不是根本不想学 → 重新对齐"为什么"

**想放弃**：
- 回到 02_训练目标.md 的"终点目标"
- 问自己：还想要那个目标吗？
- 如想 → 调整节奏
- 如不想 → 允许放弃，记录原因，重新选主题
```

## ✅ 质量检查（Skill 自身标准）

每次生成文件后，自检：

- [ ] 10 个文件都生成了吗？
- [ ] 文件里的内容是**具体到这位用户**的吗？（不是模板套话）
- [ ] 基线诊断题是**有区分度**的吗？（不是看一眼就会的弱智题）
- [ ] 目标是**可量化**的吗？（不是"提升能力"这种虚的）
- [ ] 资料是**用户真的能拿到**的吗？（不是"读某本不存在的书"）
- [ ] 复习日历是**符合用户时间**的吗？（不是一刀切每天 4 小时）
- [ ] 奖励是**用户真的会心动**的吗？（不是泛泛的"奖励自己"）
- [ ] 边界是**明确**的吗？（"不超过 90 分钟"而不是"适度休息"）
- [ ] 反省模板能**真填**吗？（不是开放问题没法答）
